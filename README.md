# 觅履 — AI简历优化平台

> 你的经历比你以为的更精彩

AI驱动的简历优化平台，核心差异化是**帮用户发现连自己都不知道的闪光点**。

## 功能

- 🔍 深度解析 — 六维度AI分析（完整性/量化程度/关键词匹配/表达清晰度/结构逻辑/格式规范）
- ✍️ 智能改写 — STAR法则自动包装，模糊描述变有力成绩
- 🎯 JD精准匹配 — 粘贴目标岗位JD，AI分析匹配度
- 📊 0-100评分 — 直观量化竞争力
- 📄 一键导出 — 多模板Word文件生成
- 🗣 模拟面试 — AI面试题库+点评报告
